# CI/CD Pipeline Implementation Project

## Project Details
* **Project Name:** cd-circleci-actions-labs
* **Course:** IBM DevOps and Software Engineering
* **Description:** This repository contains the final assignment for building and deploying a complete CI/CD pipeline using GitHub Actions, Tekton, and OpenShift.

## Features
* Linting and Unit Testing automated via GitHub Actions.
* Cloud-native pipeline orchestration via Tekton Tasks.
* Automated target deployment to Red Hat OpenShift Cluster.
